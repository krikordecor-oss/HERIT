# Naming

Le nom actuel est THERMOS.

Il a permis de lancer le projet.

Cependant, le futur produit dépasse largement le diagnostic thermique.

Le nouveau nom devra pouvoir représenter :

- la mémoire des bâtiments
- leur histoire
- leur évolution
- leur jumeau numérique
- leur résilience climatique
- leur valeur patrimoniale

Le futur nom ne devra pas être limité :

- à la chaleur
- à l'énergie
- au climat
- à un pays
- à une langue

Objectif :

Créer une marque mondiale capable d'exister pendant plusieurs décennies.
