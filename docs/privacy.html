Vos données

HERIT Lens est conçu avec un principe simple : ne demander que ce qui est nécessaire au service.

Permissions utilisées

Caméra : nécessaire pour l’expérience de visée. Dans le prototype 0.3, le flux vidéo reste affiché localement dans le navigateur et n’est pas enregistré par HERIT Lens.

Localisation : nécessaire pour rechercher les bâtiments proches. Une zone géographique approximative autour de la position est transmise à l’API RNB afin d’obtenir les bâtiments environnants.

Orientation : nécessaire pour déterminer la direction dans laquelle le téléphone est pointé.

Compte, publicité et analytics

Le prototype 0.3 ne comporte ni compte utilisateur, ni publicité, ni outil d’analytics ajouté par HERIT Lens, ni profilage commercial.

Hébergement

Le prototype est servi via GitHub Pages. Des journaux techniques peuvent être traités par l’hébergeur conformément à ses propres conditions et politiques.

Données de sécurité

HERIT applique un principe de minimisation renforcée aux informations pouvant révéler une vulnérabilité d’un bâtiment ou d’un occupant. Une observation utilisateur peut être conservée comme donnée privée ou mise en attente de vérification sans être publiée dans la base visible par d’autres utilisateurs.
